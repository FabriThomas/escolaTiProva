# Sua prova — primeiros passos

1. **Edite `ALUNO.md`** com seu nome/RA — pela própria interface web, não precisa clonar nada ainda (o workflow valida).
2. **Abra a [issue 🎯 Prova](https://github.com/FabriThomas/escolaTiProva/issues/1)** — é nela que tudo acontece.
3. **Selecione sua prova** comentando `/track <nome>` na issue (a lista está no comentário de boas-vindas). A prova é aplicada automaticamente em seguida.
4. **Clone (ou faça pull do) repo só agora**, depois do comentário “✅ Prova aplicada” na issue — os seus parâmetros de variante já estão em `variante/params.json`. Desenvolva e dê push. **Pushes não disparam correção** — quando quiser feedback, rode `/auto-correcao` na issue.
5. **Feche a issue para encerrar** — o sistema só aceita o fechamento depois de ao menos 1 `/auto-correcao` e gera o `teacher.json` de entrega.
